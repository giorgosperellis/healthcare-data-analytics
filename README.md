### Statistical Analysis | Data Management | Business Intelligence

## 📊 Project Overview

This repository documents a healthcare data analytics and
automated reporting workflow.

The project focuses on collecting, organizing, transforming,
and analyzing healthcare-related data to support statistical
reporting, performance monitoring, and management
decision-making.

The workflow combines Microsoft Excel, Power Query,
Power Pivot, SQL, and PostgreSQL.

## 🎯 Project Objectives

- Consolidate data from multiple Excel files.
- Improve data consistency and organization.
- Automate repetitive data preparation tasks.
- Support statistical analysis and KPI monitoring.
- Produce structured management reports.
- Reduce manual reporting processes.

## 🛠️ Technologies

| Technology | Purpose |
|------------|---------|
| Microsoft Excel | Data collection and reporting |
| Power Query | Data cleaning and transformation |
| Power Pivot | Data modeling and analysis |
| SQL | Data querying and organization |
| PostgreSQL | Database management |
| pgAdmin | PostgreSQL administration |

## 🔄 Data Workflow

1. Data Collection
   - Collect information from multiple Excel files.

2. Data Preparation
   - Clean, standardize, and transform data using Power Query.

3. Data Organization
   - Organize datasets using Excel Data Models
     and PostgreSQL.

4. Data Analysis
   - Calculate statistical indicators and
     analyze performance.

5. Automated Reporting
   - Generate structured Excel reports
     to support monitoring and decision-making.

## 📈 Areas of Analysis

- Healthcare statistical indicators
- Operational performance monitoring
- Digital transformation progress
- Data quality and consistency
- Management reporting

## 🔐 Data Privacy

This repository is intended to demonstrate
data analytics and reporting methodologies.

No confidential organizational information,
personal data, or production credentials
will be published.

Future examples will use synthetic or
publicly available datasets.
